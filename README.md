# Радио ВОС — прототип главной страницы

Прототип нового сайта интернет-радио Всероссийского общества слепых.
Цель — показать направление: современный дизайн, который с самого начала
соответствует требованиям доступности (ГОСТ Р 52872-2019 / WCAG 2.1).

## Что есть

- **Прямой эфир** — настоящий поток Радио ВОС, четыре уровня качества,
  громкость, подпись на экране блокировки телефона.
- **«Сейчас в эфире» и «Далее»** — по программе передач и московскому времени.
- **Программа на сегодня** — текущая передача отмечена словами, а не только цветом.
- **Анонсы** карточками.
- **Версия для слабовидящих** — размер шрифта (4 шага), 5 классических цветовых
  схем, интервалы между буквами и строками, шрифт с засечками или без,
  озвучка текста голосом браузера. Настройки запоминаются.
- **Светлая и тёмная тема** — по умолчанию как в системе.

## Доступность

- Плеер, меню и все настройки управляются с клавиатуры, фокус хорошо заметен.
- Подписи для экранных дикторов (NVDA, JAWS, VoiceOver, TalkBack).
- Без автозапуска звука и бегущих строк.
- Контраст текста не ниже 7:1, базовый размер текста — 19 px.
- При крупном шрифте раскладка сама перестраивается в одну колонку.
- Шрифт Golos Text подключён локально, без сторонних сервисов.

## Про поток на https

Поток Icecast сейчас отдаётся только по `http://radiovos.ru:9000/`.
Страница на https (например, GitHub Pages) не может воспроизводить http-звук:
браузер блокирует смешанное содержимое. В этом случае плеер предлагает открыть
эфир в новой вкладке.

Решение на стороне радио — отдавать поток по https, например через nginx:

```nginx
location /stream/ {
    proxy_pass http://127.0.0.1:9000/;
    proxy_buffering off;
}
```

После этого поменять `STREAM_BASE` в `assets/js/main.js`
на `https://radiovos.ru/stream/`.

## Запуск локально

```bash
python3 -m http.server 8080
```

и открыть http://localhost:8080 — здесь эфир играет и без https.
