# Радио ВОС

Концепция нового сайта интернет-радио Всероссийского общества слепых:
современный модульный интерфейс, доступный по ГОСТ Р 52872-2019 / WCAG 2.1.

## Устройство

Модульная оболочка, как у современных радиосервисов:

- **слева** — что сейчас в эфире, большая кнопка, качество звука и меню;
- **справа** — модули выбранного раздела: «Далее», звонок в эфир, программа
  на сегодня, передачи, анонсы;
- **снизу** — постоянный плеер.

Меню переключает правую часть без перезагрузки страницы, поэтому эфир
не прерывается при переходе по разделам. У каждого раздела свой адрес,
кнопка «Назад» работает, фокус и экранный диктор переходят к заголовку
открытого раздела.

## Доступность

- Версия для слабовидящих: 4 размера шрифта, 5 цветовых схем, интервалы,
  шрифт с засечками, озвучка текста. Настройки запоминаются.
- Плеер и меню управляются с клавиатуры, у всех элементов есть подписи для дикторов.
- При крупном шрифте раскладка сама перестраивается в одну колонку.
- Без автозапуска звука и бегущих строк.
- Фокус клавиатуры в стиле GOV.UK, в жёлтом ВОС.
- «Солнечная» схема: приглушённый жёлтый фон с пониженными бликами (по опыту RNIB).
- Крупный интерфейс (по мотивам Apple Assistive Access): огромные плитки
  «Слушать», «Программа», «Позвонить в эфир», «Тише», «Громче».
  Включается кнопкой в жёлтой шапке.
- Горячие клавиши (Alt + Shift): P — эфир или пауза, ↑ ↓ — громкость,
  M — звук, N — что в эфире, K — список клавиш.

Предыдущие версии сохранены в `/v2/` и `/v3/`.

## Про поток на https

Поток Icecast сейчас отдаётся только по `http://radiovos.ru:9000/`.
Страница на https (например, GitHub Pages) не может воспроизводить http-звук:
браузер блокирует смешанное содержимое. В этом случае плеер предлагает открыть
эфир в новой вкладке.

Решение на стороне радио — отдавать поток по https, например через nginx:

```nginx
location /stream/ {
    proxy_pass http://127.0.0.1:9000/;
    proxy_buffering off;
}
```

После этого поменять `STREAM_BASE` в `assets/js/main.js`
на `https://radiovos.ru/stream/`.

## Запуск локально

```bash
python3 -m http.server 8080
```

и открыть http://localhost:8080 — здесь эфир играет и без https.

## Данные

Программа, передачи и анонсы лежат в `assets/js/data.js`.
На боевом сайте их будет отдавать Битрикс.
